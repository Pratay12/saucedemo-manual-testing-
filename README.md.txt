# SauceDemo Manual Testing Project

## Project Overview
This is a manual testing practice project for the SauceDemo e-commerce web application.

## Application URL
https://www.saucedemo.com/

## Testing Modules
- Login and Logout
- Product Listing and Sorting
- Shopping Cart
- Checkout
- Order Confirmation

## Project Files
- Test_Cases.xlsx – Detailed manual test cases
- Test_Scenarios – High-level test scenarios
- Bug_Reports – Defect documentation
- Test_Summary – Test execution summary

## Tools Used
- Microsoft Excel / Google Sheets
- Web Browser
- GitHub

## Testing Type
Manual Functional Testing, Negative Testing, Regression Testing, and End-to-End Testing.

## Project Status
Test cases are prepared for execution. Results and defect reports will be updated based on actual testing.

## Disclaimer
This is a personal learning project created to practice manual software testing.
